# 🐍 Snake-Gamereverb

## 📖 Sobre o Projeto

Snake Game é uma versão moderna do clássico jogo da cobrinha desenvolvida com **HTML5, CSS3 e JavaScript Vanilla**.

O projeto possui interface responsiva, sistema de pontuação, recorde salvo localmente, controles para desktop e dispositivos móveis, além de efeitos visuais e sonoros que tornam a experiência mais agradável.

---

# 🎮 Demonstração

O objetivo do jogo é controlar a cobra, coletar alimentos e sobreviver pelo maior tempo possível sem colidir com as paredes ou com o próprio corpo.

---

- 🐍 Jogabilidade clássica da cobrinha

# ⚙️ Mecânicas do Jogo

### Sistema de Pontuação
- Cada alimento coletado adiciona 1 ponto.
- O recorde é salvo automaticamente no navegador.

### Sistema de Dificuldade
- A velocidade da cobra aumenta progressivamente.
- O desafio cresce conforme a pontuação aumenta.

### Condições de Derrota
- Colisão com as paredes.
- Colisão com o próprio corpo.
